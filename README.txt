ПРОГРАММА: Flight Time Tracker  
===============================

# Описание:
Данная программа рассчитывает налёт летного экипажа на основе данных из файла 'flights.csv'.  
Она анализирует рабочее время экипажа и определяет переработки:  
Суммарное время полётов за каждый месяц.  
Проверка переработок (более 80 часов в месяц, 36 часов в неделю, 8 часов в день).  
Сохранение отчёта в формате **JSON** ('report.json').  

-----------------------------------
# Необходимые файлы для работы 
-----------------------------------
#flights.csv - входные данные с рейсами.  
#report.json - выходной отчёт с рассчитанным налётом.  
#pom.xml - настройки Maven для компиляции проекта.  
#src/main/java/com/mycompany/Praktic11/  
   - 'FlightTimeCalculytor.java' - основной код программы.  
   - 'CrewMember.java' - класс с информацией о членах экипажа.  
   - 'Flight.java' - класс с данными о рейсах.  
-----------------------------------
# Формат файла 'flights.csv'  
aircraftType,aircraftNumber,departure,arrival,crew 
Boeing737,1234,2025-03-01 10:00,2025-03-01 12:30,Ivanov;Petrov 
AirbusA320,5678,2025-03-02 14:15,2025-03-02 17:45,Sidirov;Smirnov 
Boeing747,9012,2025-03-03 09:30,2025-03-03 13:00,Kuznetsov;Volkov
-----------------------------------
# Описание:  
- 'aircraftType' - тип самолёта.  
- 'aircraftNumber' - номер самолёта.  
- 'departure' - дата и время взлёта ('yyyy-MM-dd HH:mm').  
- 'arrival' - дата и время посадки ('yyyy-MM-dd HH:mm').  
- 'crew' - список членов экипажа (разделены ';').
